# 大文件编辑技能

## 原则
1. 先 Read 全文（大文件分段读），确认行号与上下文，禁止凭记忆改。
2. 局部修改一律 Edit：old_text 必须与文件逐字符一致且全局唯一；不确定唯一性时先 Grep 验证。
3. 单次 Edit 只改一处逻辑；多处修改拆成多次 Edit，逐步验证。
4. 改完必须验证：能编译就编译，不能编译就 Read 回读改动区域确认。

## 拆分重构流程
1. Read 全文，列出超行数上限的函数与可独立职责块。
2. 新文件先 Write 骨架，再逐块搬迁；每搬一块编译/回读一次。
3. 原文件只留入口与调用，删除已搬走代码。
4. 全程 Write/Edit 带 summary，框架自动备份可回退。

## 禁止
- 禁止对大文件直接整文件 Write 重写（丢失未读部分风险高）。
- 禁止一次 Edit 跨多个不相关改动。
