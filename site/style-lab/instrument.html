一道工序跑完，你可以去泡茶

Process / 工序卡
工序 01

接后端

填本地端点，或填云端 Key。Ollama / llama.cpp / LM Studio 走同一套 OpenAI 兼容协议，界面上随时切换。

BaseUrl = http://127.0.0.1:11434/v1

工序 02

下任务

对话框里一句话下达；批量活直接走命令行，无人值守跑完退出，退出码就是成败结论。

gairr -t "把 src 转 UTF-8 并跑编译" -p D:\proj
退出码 0 成功 / 1 失败 / 2 取消
工序 03

干活并自检

改文件前做任务级硬备份，每次变更写入 changelog.jsonl；编译失败自动进第 2 轮修复，不通过不算完。

.gairr/sessions/ · changelog.jsonl

02

六块面板，都是为小模型和本地机器改出来的

不是功能清单，是本地跑 Agent 时真正会卡住你的六件事，以及概尔工栈给出的解法。

Panels / 面板

五层混合检索

5 LAYERS
历史关联 → 符号标签 → 符号定义 → 文件摘要 → 向量索引，命中越靠前的层越省 token。27B 量化模型也能在 4965 个文件的项目里找对位置。
SmartSearch / MapTraceP50 < 200ms

可逆上下文压缩

32K
上下文逼近阈值时自动折叠早期轮次，只留结论与待办；原文没丢，需要时按轮号取回完整过程。长任务不再因为"忘了前面"而跑偏。
RecallHistorytalk / brief / full

项目地图

AUTO
增量扫描目录结构与文件摘要，生成 architecture.json 功能架构树；缺注释的文件和方法由大模型补说明，只写笔记不改源码。
MapAuto / Map.gairr/map.json

Skill 生态

SKILL.md
工具名兼容开放规范，市面现成技能即插即用。启动时只注入一行描述的技能清单，用到才读全文，百个技能也占不满上下文；/技能名 可强制触发。
LoadSkill可从 GitHub 安装

安全护栏

GUARD
危险命令拦截并倒计时确认，Bash 管道捕获 + 超时强杀，DbQuery 默认只读、写操作需显式开启。护栏在框架层，模型再自信也绕不过去。
Read/Write/Edit/BashDbQuery 只读

硬件状态监控

LIVE
显存、利用率、温度实时读数，本地推理的瓶颈从"猜"变成"看"：是显存不够、还是量化太狠、还是风扇压不住。
