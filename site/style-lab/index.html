方向 A

仪表台 Instrument Bench

主张：GAIRR 是一台机器，页面就是它的仪表盘。开场不是标语，是一条上电自检式的读数带——GPU、显存、温度、tok/s、上下文水位、本地端点依次点亮，右侧配一张设备铭牌与 60 秒曲线。

上电自检的仪表带 + 贯穿页面的刻度轨（ruler）；硬阴影按钮，无圆角无渐变光斑。
适合

取舍
浅色工业风偏冷静，情绪冲击不如 B；黄色大面积用会显廉价，已限制在色块与强调上。

方向 B

频道 Control Room

主张：颜色即通道。一次任务的输出被拆成五条固定通道——文件、命令、模型、硬件、事件，从会话区到日志到通知配色一致。开场是一场正在跑的任务事件流，逐行入场；左侧频道轨随滚动高亮当前段落。

Big Shoulders Display 800（超窄）
Body / 中文正文

Utility / 事件流全用等宽
IBM Plex Mono
签名元素
频道轨 + 通道图例：每个段落归属一个通道，色彩承担信息而不是装饰。
适合
想强调"可观测、可追责"，受众关心 Agent 到底动了什么、出错怎么定位。

深色底 + 多色编码在移动端会挤；五个色必须严格守住语义，一旦滥用就退化成彩虹。

方向 C

说明书 Spec Sheet

主张：这是设备铭牌与使用说明书，不是营销页。页面是三张纸：封面铭牌 + 检验章「数据不出本机」、条款一至三、条款四至五与附注。宋体大标题、楷体页边批注、粗规线表格、页脚编制/审核/批准签名位，并且真的可以打印。

刻意避开的三张"AI 默认脸"

  • 奶油底 + 高对比衬线 + 陶土橙C 用纸感的冷灰 #F6F6F2 而非奶油色，主色是蓝图蓝，陶土红只出现在一枚检验章上。
  • 近黑底 + 单一酸绿/朱红B 用深蓝灰 #0F1A21，且强调色是五个承担语义的通道色，不是一根荧光条。
  • 报纸式发丝线 + 零圆角 + 密集栏C 用 2~3px 粗规线、表格化结构与大量留白；A 用硬阴影与刻度轨，都不是报纸排版。

三个方向共同的质量底线

响应式：980 / 700 / 620px 三档断点，移动端单栏、仪表带折两列、频道轨隐藏。 键盘可达：跳转正文链接、:focus-visible 描边、频道轨用 button 而非 div。 动效克制：每页只有一处编排动作（A 上电自检 / B 事件流逐行入场），全部尊重 prefers-reduced-motion。 内容真实：文案与数字取自现有站点与项目实际（8 个内置工具、32K 上下文、五层检索、:11434、148 MB、退出码 0/1/2），没有占位文本。
