USE CASES

本地优先场景，开发不止于此

GAIRR 的骨架是一台"本地优先的 AI 开发助手"——凡是需要代码理解、项目分析、自动化处理的活，本地部署都能干。

◈本地优先代码审查
Qwen3.8-27B 本地跑代码审查，敏感源码不出本机。自动检查规范、标注意图、生成报告。
$ gairr -t "审查 src/ 下所有修改，检查是否符合 CodeStyle 规范"
▤大型项目代码理解
32K 上下文窗口 + 智能压缩，让本地模型也能读懂大型项目。LSP 精准检索，符号级代码导航。
$ gairr -t "分析这个项目的架构，找出核心模块和依赖关系"
⚙无人值守批量重构
批量重命名、迁移 API、更新依赖。本地模型逐文件处理，改完自动备份 + 编译验证。
$ gairr -t "把所有旧版 API 调用迁移到新版，改完跑编译验证"
❐敏感项目本地开发
金融、医疗、政务项目，代码数据绝不出内网。本地模型 + 本地数据库，零外发风险。
$ gairr --local -t "分析数据库 schema，生成实体类代码"
▲离线环境开发
内网机房、客户现场、出差途中，没网也能用。本地模型随叫随到，开发不中断。
$ gairr -t "这个函数报空指针，帮我定位可能的原因"
✎成本敏感场景
高频开发任务用本地模型，复杂任务切云端。按场景选模型，成本可控，效果不打折。
$ gairr -t "生成单元测试用例，覆盖所有边界条件" --model local

不是替代云端模型，而是让 本地优先成为开发工作流的第一选择，云端按需兜底。
