文档

GAIRR（概尔工栈）：工具定义、Skill 编排、循环调试、无人值守批处理。从“代码写完”到“Agent 真正干活”的最后 1 公里。

Windows x64 模型 百炼 / Kimi / Ollama 定位 本地运行 · 数据不出电脑 Skill 兼容 SKILL.md 开放生态

安装

GAIRR 是绿色单机程序，下载解压即用。安装包发布后将在下载区提供，也可以命令行方式使用：

$ gairr -t "把 src 下所有源码转为 UTF-8，并跑编译验证" -p D:\myproject
# 无人值守执行：自动备份 → Agent 干活 → 编译验证 → 钉钉通知 → 退出码表示成败
[ok] 任务完成 · 50/50 · 编译通过 · 已发钉钉通知

快速开始

第一次运行，只需三步：配置模型 Key、选择项目目录、下达任务。

1. 编辑 config.ini，填入你的模型 Key（百炼 / Kimi 二选一或都用）：

[Bailian]
BaseUrl = https://dashscope.aliyuncs.com/compatible-mode/v1
ApiKey = sk-你的key
Model = qwen-max

[Agent]
ProjectRoot = D:\myproject
MaxRounds = 50

2. 打开 GAIRR，选择项目根目录；3. 在对话区下达任务，剩下的交给 Agent。

规则写死在框架里，不靠模型自觉：改前自动备份、变更写入 changelog.jsonl 可回滚、危险命令强制确认、任务结束必发钉钉。

Skill 生态

工具命名兼容 Claude Code 通用名（Read/Edit/Bash…），直接复用开放 SKILL.md 生态——市面现成技能即插即用，你的经验也能沉淀成技能：

└── skills/
    └── pdf-form-filler/
        ├── SKILL.md   ← YAML frontmatter（name/description）+ 操作步骤
        ├── reference/ ← 详细指令文档（用 Read 按需读取）
        └── scripts/   ← 辅助脚本（经 Bash 执行）
  • 启动时只把技能清单（每行一个描述）注入 system prompt，用到才读全文，百个技能也占不满上下文
  • 输入 /技能名 可强制触发，跳过模型语义判断
  • 技能管理界面支持列表 / 新建 / 编辑 / 导入
